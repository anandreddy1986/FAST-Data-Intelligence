GDS v1.19 adds NVMe P2PDMA support using upstream Linux NVMe drivers (eliminating custom patches), new scatter-gather cuFile APIs for multi-buffer I/O, and Amazon FSx for Lustre integration. GDS is now part of CUDA.

2025

SPDK Transitions to Linux Foundation

Intel transferred the Storage Performance Development Kit (SPDK) to the Linux Foundation for long-term sustainability. SPDK 26.5 is the latest release. CSI driver brings SPDK to Kubernetes via NVMe-oF.

Mid-2025

Linux Kernel NVMe-TCP Receive Offload Patches Reach v29

The long-running NVMe-TCP receive offload patchset reaches v29 on net-next, adding NIC driver hooks for queue init/teardown, IO operation setup with async completions, and CRC offload on receive. Tested on Mellanox ConnectX-7.

18 Nov 2025

CXL 4.0 Specification Released — Doubles Bandwidth to 128 GT/s

CXL 4.0 doubles link rate from 64 to 128 GT/s, adds bundled ports enabling up to 1.5 TB/s connections, and enhances memory RAS features. Announced at Supercomputing 2025. Multi-rack memory pooling targeted for late 2026-2027.
